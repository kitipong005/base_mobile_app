ข้อแนะนำก่อนสร้าง Base Widgets:

  1. วางแผน Design System ก่อน

  lib/core/design_system/
  ├── colors.dart          # Color palette
  ├── typography.dart      # Text styles
  ├── spacing.dart         # Spacing constants
  └── app_theme.dart      # Theme configuration

  2. Base Widgets ที่ควรมี

  - BaseButton (Primary, Secondary, Text, Icon)
  - BaseTextField (Normal, Password, Search)
  - BaseCard (Different elevations/styles)
  - BaseDialog (Alert, Confirmation, Loading)
  - BaseAppBar (Different variants)
  - BaseScaffold (With consistent padding/structure)
  - BaseError (Error states)
  - BaseLoading (Loading indicators)
  - BaseEmpty (Empty states)

  3. Structure ที่แนะนำ

  lib/presentation/widgets/base/
  ├── buttons/
  │   ├── base_button.dart
  │   ├── base_icon_button.dart
  │   └── base_text_button.dart
  ├── inputs/
  │   ├── base_text_field.dart
  │   └── base_search_field.dart
  ├── layout/
  │   ├── base_scaffold.dart
  │   ├── base_card.dart
  │   └── base_app_bar.dart
  ├── feedback/
  │   ├── base_dialog.dart
  │   ├── base_snackbar.dart
  │   └── base_loading.dart
  └── states/
      ├── base_error.dart
      └── base_empty.dart

  4. หลักการสำคัญ

  - Consistent Naming: BaseXxx format
  - Theme Integration: ใช้ Theme.of(context)
  - Customizable: รับ parameters สำหรับ customization
  - Accessibility: รองรับ accessibility
  - Documentation: Comment อธิบายการใช้งาน

  5. เริ่มจาก Theme Configuration

  ควรสร้าง app_theme.dart ก่อนเพื่อกำหนด:
  - Colors
  - Typography
  - Button styles
  - Input decoration themes
  - Card themes

  คุณอยากเริ่มจากอะไรก่อนครับ? แนะนำให้เริ่มจาก:
  1. Theme Configuration - กำหนด design system
  2. BaseButton - เป็น component ที่ใช้บ่อยที่สุด
  3. BaseTextField - สำหรับ forms
  4. BaseScaffold - layout structure

  -------------------------------------------------------------------
  ได้สร้างระบบ Base Widgets ที่สมบูรณ์แบบสำหรับแอปพลิเคชัน Flutter แล้ว โดยประกอบด้วย:

  สิ่งที่สร้างเสร็จแล้ว:

  1. Design System Foundation

  - colors.dart - ระบบสีที่สมบูรณ์
  - typography.dart - ระบบ Typography
  - spacing.dart - ระบบ Spacing และ Layout
  - app_theme.dart - การกำหนดค่า Material Theme

  2. Base Button Components

  - base_button.dart - ปุ่มหลักที่รองรับ 5 แบบ (primary, secondary, outline, text, danger)
  - รองรับ 3 ขนาด (small, medium, large)
  - มี Loading state, Icon support, Factory methods

  3. Base Input Components

  - base_text_field.dart - Text field ที่รองรับหลายประเภท (text, email, password, phone, number, search)
  - base_dropdown.dart - Dropdown component พร้อม custom items
  - base_checkbox.dart - Checkbox และ Checkbox list

  4. Base Layout Components

  - base_card.dart - Card component 3 แบบ (elevated, outlined, filled)
  - base_container.dart - Container component ที่ปรับแต่งได้
  - base_scaffold.dart - Scaffold พร้อม AppBar ที่ปรับแต่งได้

  5. Base Feedback Components

  - base_dialog.dart - Dialog component หลายประเภท (info, success, warning, error, confirmation)
  - base_snackbar.dart - Snackbar component พร้อม icons และ actions

  6. Base State Components

  - base_loading.dart - Loading indicators หลายแบบ (circular, linear, dots, spinner)
  - base_empty.dart - Empty state components
  - base_error.dart - Error state components

  จุดเด่นของระบบนี้:

  ✅ ใช้งานง่าย - มี Factory methods สำหรับการใช้งานแบบง่าย
  ✅ ปรับแต่งได้ - สามารถ override properties ได้ตามต้องการ
  ✅ สอดคล้องกัน - ใช้ design system เดียวกันทั้งแอป
  ✅ ครอบคลุม - มี components สำหรับใช้งานทั่วไป
  ✅ Type-safe - ใช้ Enums สำหรับกำหนดประเภทและขนาด
  ✅ Accessibility - รองรับ semantics และ Material Design guidelines
